# 对局开始/暂停 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给对局页加显式「开始/暂停/继续」:进页不自动开局,点开始才连服务器;暂停是整局总开关(棋盘+AI+弹幕+语音+冷场闲聊一起停),服务端感知暂停以免空耗。

**Architecture:** 服务端 ws-server 维护 `pausedGames` 集合,暂停期间停冷场定时器、跳过 move/say/idle 刺激;前端 PlayPage 状态机加 `idle`/`paused`,按状态切「开始/暂停/继续」单按钮,暂停时发 WS pause + 调 server-tts 新增的 `stopVoice()` 急停语音。

**Tech Stack:** TypeScript(ESM,`.js` 后缀)、Fastify 4 + @fastify/websocket、React 18、vitest(server WS 集成测试;前端 typecheck+build + 人工)。

参考 spec:[2026-06-21-对局开始暂停-design.md](../specs/2026-06-21-对局开始暂停-design.md)

## Task 2: server-tts 语音急停 stopVoice

**Files:** Modify `web/src/voice/server-tts.ts`

闸门:`npm -w web run typecheck && npm -w web run build`(server-tts 是 DOM/网络模块,项目现无其单测,本函数随之走构建闸门)。

- [ ] **Step 1: 加 stopVoice** — 在 `server-tts.ts` 的公开 API 区(`export function speakServer` 附近)加:
```ts
/** 立即静音:停当前播放 + 清空预合成队列。暂停整局时调用,确保正在播/排队的语音立刻停。 */
export function stopVoice(): void {
  queue = []
  if (audioEl) {
    try { audioEl.pause() } catch { /* 忽略 */ }
    audioEl.src = ''
  }
}
```
(`queue` 与 `audioEl` 是模块级变量,已存在。)

- [ ] **Step 2: typecheck + build** — Run: `npm -w web run typecheck && npm -w web run build` → 均干净。

- [ ] **Step 3: Commit** —
```
git add web/src/voice/server-tts.ts
git commit -m "feat(pause): server-tts 加 stopVoice(停当前播放+清队列)"
```

**Context:** `web/src/voice/server-tts.ts` 顶部已有 `let queue: QueueItem[] = []` 与 `let audioEl: HTMLAudioElement | null = null`。`stopVoice` 不改动 drain/解锁逻辑;清空 queue 后 drain 的 while 循环在当前项结束后自然停,`audioEl.src=''` 让当前播放停止。

- [ ] **Step 3: 开始/暂停/继续 处理函数** — 在组件内(`handleMove` 附近)加三个处理函数:
```ts
  function handleStart() {
    startNewConnection(mode, side)
  }
  function handlePause() {
    if (status !== 'playing' || gameId === null) return
    wsRef.current?.send({ type: 'pause', gameId })
    stopVoice()
    cancelSpeech()
    setStatus('paused')
    setStatusMsg('已暂停 — 点「继续」恢复')
    setStatusError(false)
  }
  function handleResume() {
    if (status !== 'paused' || gameId === null) return
    wsRef.current?.send({ type: 'resume', gameId })
    setStatus('playing')
    setStatusMsg('已继续,请走棋')
    setStatusError(false)
  }
```
(`cancelSpeech` 是已 import 的浏览器 TTS 取消;一并停掉浏览器回退语音。)

- [ ] **Step 4: 模式/执方在 idle 态只设值不重开** — 把 `handleModeChange`/`handleSideChange` 改为仅在已有对局时重开:
```ts
  function handleModeChange(newMode: GameMode) {

    if (status !== 'idle') handleRestart(newMode, side)
  }
  function handleSideChange(newSide: HumanSide) {
    setSide(newSide)
    if (status !== 'idle') handleRestart(mode, newSide)
```

- [ ] **Step 5: 主控制按钮 + onSay 守卫** — 在状态栏(`<div style={styles.statusBar} ...>` 块内,`statusMsg` 之后)加随状态切换的主按钮:
