# M2 智能分析层 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让用户下完一局后,系统能逐手诊断丢分与失误类型、跨局聚合出弱点画像、从败局生成"该走哪"训练题、并用成长曲线与两段历史对比量化进步——全部基于真实 Pikafish 评分,后端逻辑纯函数 + TDD,前端图表呈现。

**Architecture:** 在 M1 的 `server/`(Node + Fastify + ws + better-sqlite3 + Pikafish UCI)上扩一条**局后分析管线**:`diagnose-game` 取出某局存档 → 对每个局面调引擎拿最佳着评分(相邻手之间复用局面分析结果,N 手只需 N+1 次分析)→ 纯函数算 cp 丢分 / 阶段 / 主题标签 → 落 `move_annotations`,并聚合出该局 `growth_metrics`。弱点画像与历史对比是对这两张表的**只读聚合查询**(个人单机数据量小,先不物化弱点表)。前端加三页(单局诊断 / 成长 / 训练),图表库先 spike 选型再适配。诊断走后台、不阻塞对弈;实时诊断留 hook。

**Tech Stack:** 沿用 M1(Node 20+/25, TypeScript, Fastify, ws, better-sqlite3, Vitest, Vite, React, Pikafish UCI)。前端图表库在 Task 10 选型确定(候选 recharts / 轻量 SVG 自绘)。

**约定(承接 M1):**
- 着法用 Pikafish 坐标记法(如 `h2e2`);`scoreCp` 一律为**当前走子方视角**的厘兵分,正数=走子方优;mate 映射为 `±(30000 - n)` 极值(见 M1 `uci-parse.ts` 的 `MATE_BASE`)。
- **cp 丢分(centipawn loss)定义**:某手 `move` 的丢分 = `bestCp(before) - playedValue`,其中 `playedValue`(走子方视角)= 走该手后局面的对手视角最佳评分取反 = `-bestCp(after)`。故 `loss = bestCp(before) + bestCp(after)`,再 `max(0, ·)` 截断(引擎噪声/更优着导致的负值归零)。两端均为各自走子方视角。
- 所有纯函数与边界逻辑均带测试;外部库(图表)先验证 API 再适配,降级项写明。
- 频繁提交,每个 Task 结束 commit。

## 数据模型(扩 `schema.sql`,均 `CREATE TABLE IF NOT EXISTS`,零迁移)

> 取舍:M1 `moves` 表不动(免 ALTER 迁移);诊断结果存独立表,按 `(game_id, ply)` 对应 `moves`。弱点画像 design §6 列了 `weakness_profile` 物化表,但个人单机数据量小,**先用对 `move_annotations` 的聚合查询**实现(YAGNI;数据量大再物化)。`growth_metrics` 需物化(逐局快照=成长曲线的时间序列点)。

```sql
-- 逐手诊断标注(局后分析产出)
CREATE TABLE IF NOT EXISTS move_annotations (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  game_id INTEGER NOT NULL REFERENCES games(id),
  ply INTEGER NOT NULL,               -- 对应 moves.ply
  side TEXT NOT NULL,                 -- red | black
  cp_loss INTEGER NOT NULL,           -- 该手丢分(>=0,走子方视角)
  best_move TEXT NOT NULL,            -- 引擎该局面最佳着(Pikafish 记法)
  phase TEXT NOT NULL,                -- opening | midgame | endgame
  theme TEXT NOT NULL,                -- ok | inaccuracy | mistake | blunder | missed_mate | hangs_piece
  UNIQUE (game_id, ply)
);
CREATE INDEX IF NOT EXISTS idx_annot_game ON move_annotations(game_id, ply);

-- 逐局成长指标快照(成长曲线 / 历史对比的数据点)
CREATE TABLE IF NOT EXISTS growth_metrics (
  game_id INTEGER PRIMARY KEY REFERENCES games(id),
  analyzed_at TEXT NOT NULL,
  human_side TEXT NOT NULL,           -- 被分析方=人(red|black)
  acpl INTEGER NOT NULL,              -- 人方平均每手丢分
  accuracy REAL NOT NULL,             -- 0..100,由 ACPL 映射
  est_elo INTEGER NOT NULL,           -- 由 ACPL 估算
  opening_acpl INTEGER NOT NULL,
  midgame_acpl INTEGER NOT NULL,
  endgame_acpl INTEGER NOT NULL,
  blunders INTEGER NOT NULL,          -- 人方漏着数
  mistakes INTEGER NOT NULL,
  result TEXT                         -- red|black|draw|null(承接 games.result)
);
```

## 关键设计决策(实现期遵循,勿临时改向)

| 决策点 | 选择 | 理由 |
|---|---|---|
| 诊断时机 | **局后批量**,`POST /games/:id/diagnose` 触发 | M1 人着 `score_cp` 为 null;局后统一对每局面分析一次最稳最省;实时诊断留 hook |
| 引擎复用 | 复用 M1 单例 `UciEngine`(队列串行) | 诊断分析走同一队列,不与对弈抢话;后台异步 |
| 分析深度 | `movetime`/`depth` 可配,默认 `depth: 12` | 诊断要评估质量;个人单机不在意几秒 |
| 局面分析复用 | 第 i 手 `after` = 第 i+1 手 `before`,N 手共 N+1 个局面各分析 1 次 | 砍掉一半引擎调用 |
| 被分析方 | 只标注**人方**的手(`games.human_side`) | 成长画的是用户棋力,不计 AI 方 |
| 弱点画像 | 对 `move_annotations` 聚合查询(GROUP BY phase, theme),不建物化表 | YAGNI;个人数据量小 |
| 估算 Elo | ACPL → Elo 单调递减映射(分段近似),标注粗估、可调 | 无在线对局无法精确;粗估足够看趋势 |
| 历史对比文字 | M2 出**规则版模板摘要**;LLM 措辞留 `ReportProvider` 接口(M3 接) | LLM 属 M3;先让数据/结论可用 |
| 子力失调标签 | M2 **不做**(留 M3+),`theme` 不含它 | 需更深局面理解,投入产出比低;先覆盖 loss/mate/丢子可判的 |

```ts
/**
 * 计算某一手的 centipawn 丢分。
 * @param beforeBestCp 走子前局面引擎最佳着评分(走子方视角)
 * @param afterBestCp  走子后局面引擎最佳着评分(此时轮对手,对手视角)
 * @returns 丢分(>=0)。playedValue(走子方视角)= -afterBestCp,
 *          loss = beforeBestCp - playedValue = beforeBestCp + afterBestCp,截断到 0。
 */
export function cpLoss(beforeBestCp: number, afterBestCp: number): number {
  return Math.max(0, beforeBestCp + afterBestCp)
}
```

```ts
import type { Phase } from '../types.js'

/** 数 FEN 棋盘段里的车(r/R)、马(n/N)、炮(c/C)总数 */
export function countMajors(fen: string): number {
  const board = fen.split(' ')[0]
  let n = 0
  for (const ch of board) {
    if ('rRnNcC'.includes(ch)) n++
  }
  return n
}

const ENDGAME_MAJORS = 6   // 双方车马炮合计 <=6(原 12 的一半)→ 残局
const OPENING_MAX_PLY = 16 // 前 8 回合

/** 按子力 + 手数分类对局阶段;子力少先判残局,再判开局,否则中局 */
export function classifyPhase(ply: number, fenAfter: string): Phase {
  if (countMajors(fenAfter) <= ENDGAME_MAJORS) return 'endgame'
  if (ply <= OPENING_MAX_PLY) return 'opening'
  return 'midgame'
}
```

```ts
import type { Theme } from '../types.js'

export interface ThemeSignals {
  cpLoss: number
  hadMateBefore: boolean   // 走子前己方已有(被引擎判定的)杀
  tookMate: boolean        // 这手是否就是通向杀的着(= 实走着等于引擎最佳着且仍是 mate)
  lostMaterial: boolean    // 这手后己方净子力减少(由前后子力计数粗判)
}

const BLUNDER = 300
const MISTAKE = 150
const INACCURACY = 50
const HANGS_MIN_LOSS = 200

/** 失误主题分类;优先级:错失杀棋 > 丢子 > 丢分分级 */
export function classifyTheme(s: ThemeSignals): Theme {
  if (s.hadMateBefore && !s.tookMate) return 'missed_mate'
  if (s.lostMaterial && s.cpLoss >= HANGS_MIN_LOSS) return 'hangs_piece'
  if (s.cpLoss >= BLUNDER) return 'blunder'
  if (s.cpLoss >= MISTAKE) return 'mistake'
  if (s.cpLoss >= INACCURACY) return 'inaccuracy'
  return 'ok'
}
```

```ts
/** 准确率(0..100):ACPL 指数衰减。常量 300 为启发式,可调。 */
export function accuracyFromAcpl(acpl: number): number {
  return Math.round(100 * Math.exp(-Math.max(0, acpl) / 300) * 10) / 10
}

/** 估算 Elo:分段线性 2600 - 6*ACPL,钳制 [600, 2600]。粗估,可调。 */
export function estimateElo(acpl: number): number {
  const raw = 2600 - acpl * 6
  return Math.max(600, Math.min(2600, Math.round(raw)))
}
```

```ts
import type { GamesRepo } from '../store/games-repo.js'
import type { AnalysisRepo } from '../store/analysis-repo.js'
import type { EngineLine, Side, MoveAnnotation } from '../types.js'
import { cpLoss } from './cploss.js'
import { classifyPhase } from './phase.js'
import { classifyTheme } from './tags.js'
import { accuracyFromAcpl, estimateElo } from './elo.js'

interface EngineLike {
  analyze(fen: string, opts: { multipv: number; depth?: number; movetime?: number }): Promise<EngineLine[]>
}

export interface DiagnoseDeps {
  games: GamesRepo
  analysis: AnalysisRepo
  engine: EngineLike
  clock: () => string
  depth?: number // 默认 12
}

export interface DiagnoseSummary {
  gameId: number
  annotated: number
  humanSide: Side
  acpl: number
  estElo: number
  blunders: number
  mistakes: number
}

/** 数 FEN 棋盘段里某一方的棋子总数(大写=red,小写=black) */
function countSidePieces(fen: string, side: Side): number {
  const board = fen.split(' ')[0]
  let n = 0
  for (const ch of board) {
    if (!/[a-zA-Z]/.test(ch)) continue
    const isRed = ch === ch.toUpperCase()
    if ((side === 'red') === isRed) n++
  }
  return n
}

export async function diagnoseGame(deps: DiagnoseDeps, gameId: number): Promise<DiagnoseSummary> {
  const game = deps.games.getGame(gameId)
  if (!game) throw new Error(`game not found: ${gameId}`)
  const moves = deps.games.getMoves(gameId)
  if (moves.length === 0) throw new Error(`game has no moves: ${gameId}`)

  const fens = [game.startFen, ...moves.map((m) => m.fenAfter)]
  const depth = deps.depth ?? 12
  const analyses: EngineLine[] = []
  for (const fen of fens) {
    const lines = await deps.engine.analyze(fen, { multipv: 1, depth })
    analyses.push(lines[0])
  }

  for (let i = 0; i < moves.length; i++) {
    const m = moves[i]
    const before = analyses[i]
    const after = analyses[i + 1]
    const loss = cpLoss(before.scoreCp, after.scoreCp)
    const hadMateBefore = before.mate != null && before.mate > 0
    const tookMate = hadMateBefore && m.move === before.move
    const twoLater = fens[i + 2]
    const lostMaterial =
      twoLater != null && countSidePieces(fens[i], m.side) > countSidePieces(twoLater, m.side)

    const annotation: MoveAnnotation = {
      gameId,
      ply: m.ply,
      side: m.side,
      cpLoss: loss,
      bestMove: before.move,
      phase: classifyPhase(m.ply, m.fenAfter),
      theme: classifyTheme({ cpLoss: loss, hadMateBefore, tookMate, lostMaterial }),
    }
    deps.analysis.saveAnnotation(annotation)
  }

  const human = deps.analysis.getAnnotations(gameId).filter((a) => a.side === game.humanSide)
  const mean = (xs: number[]) => (xs.length ? Math.round(xs.reduce((a, b) => a + b, 0) / xs.length) : 0)
  const acpl = mean(human.map((a) => a.cpLoss))
  const byPhase = (p: string) => mean(human.filter((a) => a.phase === p).map((a) => a.cpLoss))
  const blunders = human.filter(
    (a) => a.theme === 'blunder' || a.theme === 'missed_mate' || a.theme === 'hangs_piece',
  ).length
  const mistakes = human.filter((a) => a.theme === 'mistake').length

  deps.analysis.saveGrowthMetric({
    gameId,
    analyzedAt: deps.clock(),
    humanSide: game.humanSide,
    acpl,
    accuracy: accuracyFromAcpl(acpl),
    estElo: estimateElo(acpl),
    openingAcpl: byPhase('opening'),
    midgameAcpl: byPhase('midgame'),
    endgameAcpl: byPhase('endgame'),
    blunders,
    mistakes,
    result: game.result,
  })

  return { gameId, annotated: moves.length, humanSide: game.humanSide, acpl, estElo: estimateElo(acpl), blunders, mistakes }
}
```

```ts
import type { Drill, MoveAnnotation, Side } from '../types.js'
import type { MoveRow } from '../store/games-repo.js'

export interface DrillInput {
  gameId: number
  humanSide: Side
  startFen: string
  moves: MoveRow[]
  annotations: MoveAnnotation[]
  maxDrills?: number // 默认 5
}

export function generateDrills(input: DrillInput): Drill[] {
  const max = input.maxDrills ?? 5
  const byPly = new Map(input.moves.map((m) => [m.ply, m]))
  const fenBefore = (ply: number): string =>
    ply <= 1 ? input.startFen : byPly.get(ply - 1)?.fenAfter ?? input.startFen

  return input.annotations
    .filter((a) => a.side === input.humanSide && a.theme !== 'ok')
    .sort((a, b) => b.cpLoss - a.cpLoss)
    .slice(0, max)
    .map((a) => ({
      gameId: input.gameId,
      ply: a.ply,
      fen: fenBefore(a.ply),
      bestMove: a.bestMove,
      playedMove: byPly.get(a.ply)?.move ?? '',
      cpLoss: a.cpLoss,
      theme: a.theme,
    }))
}
```

```ts
import type { GrowthMetric } from '../types.js'

export interface WindowStats {
  games: number
  acpl: number
  accuracy: number
  estElo: number
  blundersPerGame: number
}

export interface CompareReport {
  before: WindowStats
  after: WindowStats
  deltas: { acpl: number; accuracy: number; estElo: number; blundersPerGame: number }
  summary: string
}

function aggregate(ms: GrowthMetric[]): WindowStats {
  const n = ms.length
  if (n === 0) return { games: 0, acpl: 0, accuracy: 0, estElo: 0, blundersPerGame: 0 }
  const sum = (f: (m: GrowthMetric) => number) => ms.reduce((a, m) => a + f(m), 0)
  return {
    games: n,
    acpl: Math.round(sum((m) => m.acpl) / n),
    accuracy: Math.round((sum((m) => m.accuracy) / n) * 10) / 10,
    estElo: Math.round(sum((m) => m.estElo) / n),
    blundersPerGame: Math.round((sum((m) => m.blunders) / n) * 100) / 100,
  }
}

export function compareWindows(before: GrowthMetric[], after: GrowthMetric[]): CompareReport {
  const b = aggregate(before)
  const a = aggregate(after)
  const deltas = {
    acpl: a.acpl - b.acpl,
    accuracy: Math.round((a.accuracy - b.accuracy) * 10) / 10,
    estElo: a.estElo - b.estElo,
    blundersPerGame: Math.round((a.blundersPerGame - b.blundersPerGame) * 100) / 100,
  }
  return { before: b, after: a, deltas, summary: summarize(b, a, deltas) }
}

function summarize(b: WindowStats, a: WindowStats, d: CompareReport['deltas']): string {
  if (b.games === 0 || a.games === 0) return '样本不足:两个时间段都需要至少一局已诊断的对局才能对比。'
  const elo = d.estElo > 0 ? `提升约 ${d.estElo} 分` : d.estElo < 0 ? `下降约 ${-d.estElo} 分` : '基本持平'
  const acpl = d.acpl < 0 ? `平均每手丢分从 ${b.acpl} 降到 ${a.acpl}(更精准)`
    : d.acpl > 0 ? `平均每手丢分从 ${b.acpl} 升到 ${a.acpl}(更毛糙)`
    : `平均每手丢分持平(${a.acpl})`
  const blunder = d.blundersPerGame < 0 ? `每局漏着减少 ${-d.blundersPerGame}`
    : d.blundersPerGame > 0 ? `每局漏着增加 ${d.blundersPerGame}` : '每局漏着持平'
  return `近 ${a.games} 局对比此前 ${b.games} 局:估算棋力${elo};${acpl};${blunder}。`
}
```
