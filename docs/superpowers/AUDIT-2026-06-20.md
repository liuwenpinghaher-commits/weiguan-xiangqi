## P0 — 正确性硬伤(会被一眼看穿 / 污染数据)

1. **【bug】和棋/长将规则错**:`isGameOver` 全靠 elephantops,而它用 **50 半回合(=25 回合)** 判和(非象棋的 60 回合),且**完全没有重复局面/长将/长捉判定**。后果:25 回合无吃子被提前判和;**长将循环永不终止**(双方不变招会无限走)。设计 §8/§10 明确要"长将长捉判负、单独测试"。`position.ts:149` + elephantops 源。
2. **【bug】mate 丢分爆值污染 ACPL/Elo**:`uci-parse.ts:28` 把杀棋映射成 ~30000,`cploss` 取算术平均进 ACPL,`elo=2600-6×ACPL`。**一局只要出现一次错失杀棋/被将,单手 cpLoss≈3万** → 整局 ACPL 拉到几千 → Elo 直接钳到 600 下限。成长曲线出现无意义断崖。`cploss.test.ts:18` 自证。
3. **【风险·未验证】视角转换桥无测试**:`game-session.ts:132` `redCp = aiSide==='red'?aiCp:-aiCp` 是全系统唯一"走子方视角→红方视角"的桥,**零测试**。若写反,**黑方走子时所有弹幕会把优劣判反**(把"黑大优"说成"红大优")——和"弹幕没意义"同源、更隐蔽。同理 `cploss` 正确性依赖"引擎=走子方视角"这一**从未对真实引擎验证**的假设。

## P1 — 招牌功能是死代码/开环(功能不完善、业务不闭环)

4. **【死码】拟人对手模式不可达**:`humanlike` 全仓只在类型定义出现,前端 `PlayPage.tsx:63` 写死 `mode:'coach'`。设计 §2 核心"陪练+拟人,两者皆有可切换"——**一半功能走不到**。
5. **【未接·灵魂缺失】角色之间不互动**:`chat-engine.buildPrompt` 不含"同回合其他角色刚说的话"(`lastText` 只用于去重、不进 prompt),各角色**并行独白**,永远不会接话/拉踩/抬杠/打圆场。设计 §5.3 反复称这是"灵魂",**完全没做**。"角色彼此关系旧账"同样无承载。
6. **【开环·灵魂缺失】跨会话长期记忆不生效**:① `kind:'fact'` **全仓零写入**;② grounding 检索只取 `['fact','insight']`,把每条弹幕 episode **排除在外**;③ insight **只在将死局末**产生 → 和棋/认输/中途关页面**永不沉淀记忆**。三者叠加 = 下次开局 grounding 恒为"(还不了解)"。"像老棋友记得你"未达成。`chat-engine.ts:69/103`、`reflection.ts`、`ws-server.ts:104`。
7. **【开环】M2 成长飞轮断裂**:a) 诊断**不自动**(局末不触发)且 **UI 无入口**(对局结束只给"查看复盘",Nav 只有"对局/成长",analysis/training 只能手敲 hash)→ 普通用户**走不到分析层**;b) 训练**开环**:`TrainingPage.answer()` 只前端比对,**不回写、不更新弱点**;c) 专项陪练**未做**(裁剪 M2.5);d) 历史对比的 **LLM 自然语言报告未做**(只有规则模板,`ReportProvider` 接口实际不存在)。
8. **【未接】茶馆"活气"缺失**:冷场闲聊**永不触发**(idle 张力 0.15 < 阈值 0.45);`blunder/brilliant/long_think/lose_streak/topic_open` **5 种刺激零构造点**(诊断结果与聊天没打通);coach 均势局张力低 → 弹幕稀疏;prompt **从不引导棋招/棋坛掌故**(只"针对这步说一句 ≤25字")。设计 §5.3"懂棋会讲掌故/多刺激驱动/闲聊"大面积落空。
9. **【未接】导演心理/EDDA 是空壳**:`lastMoveMs`(长考)采集了**却从不被 director 读取**;"悔棋频率/失误连发/参与度趋势(EDDA)"字段都不存在。§5.2 标为"方案灵魂"的动态心流调难度未落地(只剩"连败下调评分带"的静态规则)。
10. **【未接】Pikafish 强度档没用**:`UCI_Elo/Skill Level/LimitStrength`(§4 点名的"控盘技术支点")**从未下发**,拟人只靠 MultiPV=5 浅采样近似;`estimateElo` 只是事后估算、不回馈引擎。

## P2 — 数据模型 / 运维不闭环

11. **【缺失·未声明】`messages` 表不存在 → 聊天不持久化**:设计 §6 明列 `messages`,实际只建 5 张表。弹幕只渲染 + 写 `persona_memory.episode`,**刷新/重连即永久丢失**;复盘 `/games/:id` 不含对话。且此缺口**未在任何"已知简化"中声明**。
12. **【缺失·未声明】数据导出 + 棋谱导入导出零实现**:§8"数据可一键导出"、§5.5/§4"棋谱标准格式互通"——**无任何 export/PGN/ICCS 端点或导入解析**。数据锁死在 SQLite。
13. **【运维】引擎/LLM 硬绑启动**:`index.ts` 缺 `PIKAFISH_PATH` 直接 `exit(1)`;`ws-server` 无条件 `new VolcanoLLM()`,缺 ARK key 即抛 → **没引擎连"只聊天/只看复盘"都起不来;没 ARK key 连纯本地对弈都起不来**。与"里程碑可独立、引擎/LLM 解耦"的设计相悖。
14. **【运维】无生产路径 + 状态重启即失**:只有 `dev`(tsx watch),无 `build`/`start`;DB 路径相对 cwd(换目录"丢档");无优雅关闭(SIGTERM 不清引擎子进程/WAL);对局进行态全在内存 Map,**重启后无法续局**(只能开新局)。

## P3 — 前端产品化欠账

15. **【缺失】零响应式**:无 `viewport` meta、无任何 media query、棋盘宽度 480 + 聊天 260 固定像素 → **窄屏溢出、移动端不可用**。与"Web 优先→移动 app、响应式铺路"定位直接冲突。
16. **【缺失】一键换边**:`humanSide` 写死 `'red'`(后端已支持),§8 承诺的换边无入口。
17. **【缺失】WS 断连无自愈**:断线只提示"请刷新",无重连;重连也是新开局不续局。
18. **【缺失】导航/可发现性**:诊断、训练页用户**无法从界面到达**。
19. **【弱】棋盘交互反馈**:无上一步标记/走法高亮/将军提示;AI 思考时不锁盘;非法着法只在状态栏一行小字;`addressee` 直接显示 `human`/拼音 id(穿帮);对局结束**不显示输赢**(契约缺 result);分析三页裸 HTML 与茶馆风割裂、`GrowthPage` 静默吞错。
20. **【弱】无障碍≈0 / 语音打磨**:全站 0 个 aria、emoji 按钮无 label、棋盘键盘不可达;语音开关不持久化;无中文嗓子时静默失败仍显示🔊;TTS 队列无管理(群聊时语音严重滞后)。

## P4 — 测试体系 / 契约一致性

21. **【测试】零集成测试**:`ws-server.ts`(接线层)、`game-session` 的刺激/视角/张力分支(测试不传 `onStimulus` 全部短路)、`buildContext`/`buildPrompt`/`reflect 触发逻辑`——CodeGraph 确认均 **no covering tests**。
22. **【测试】假绿清单**:`describe-move` 只喂手写常量(从不喂 `Position.fen()` 真实输出→两套 FEN 假设没对齐);`reflection` 断言"含急躁"但那是 FakeLLM 自己返回的;真实引擎/真实 LLM 从未进过测试。绿测试证明"零件合格"≠"系统正确"。
23. **【测试】前端零测试设施**:1161 行(坐标转换、ws 契约、语音、路由)全靠 typecheck+build;坐标朝向(`Board.tsx:21` 自承"待真机核对")是 position 同类高危点却无测试。
24. **【契约】不一致隐患**:scoreCp 两套视角约定(types.ts:5 vs :118);FEN 两套假设(position/elephantops vs describe-move 自写 parseBoard);`ChatLine` 前端缺 gameId、PersonaId 放宽为 string;PersonaId 前端三处硬编码,后端加角色前端无报错。
